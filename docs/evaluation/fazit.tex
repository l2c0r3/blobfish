aktuell nur das Kriterium \enquote{Rechenzeit} existiert und für die Evaluationsstrategie das Kriterium \enquote{Qualität}. \\

genommen werden kann. Jede Variante enthält gemäss seiner Rangliste von seiner jeweiligen Disziplin Punkte: der Erstplazierte
